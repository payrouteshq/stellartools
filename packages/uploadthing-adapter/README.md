# @stellartools/uploadthing-adapter

UploadThing adapter for Stellar Tools. Connect UploadThing file uploads to Stellar Tools for asset management.

## Installation

```bash
pnpm add @stellartools/uploadthing-adapter
```

## Usage

```ts
import { createStellarUploadRouter } from "@stellartools/uploadthing-adapter";
```

## Development

```bash
pnpm build
```
