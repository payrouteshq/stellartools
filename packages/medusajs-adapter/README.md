# @stellartools/medusajs-adapter

MedusaJS adapter for Stellar Tools. Add Stellar-native payment processing to your MedusaJS storefront.

## Installation

```bash
pnpm add @stellartools/medusajs-adapter
```

## Usage

```ts
import StellarToolsPaymentProvider from "@stellartools/medusajs-adapter";

// Register as a payment provider in medusa-config.js
```

## Development

```bash
pnpm build
```
