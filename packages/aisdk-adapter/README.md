# @stellartools/aisdk-adapter

Vercel AI SDK adapter for Stellar Tools. Lets you use Stellar Tools resources as AI SDK tools.

## Installation

```bash
pnpm add @stellartools/aisdk-adapter
```

## Usage

```ts
import { stellartools } from "@stellartools/aisdk-adapter";

// Use Stellar Tools as AI tools in your AI SDK pipeline
```

## Development

```bash
pnpm build        # tsup build
```
